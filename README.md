# HedgeAiCare Bot 🤖🦔

Умный Telegram-бот для заботы о вашем колючем друге. Получайте персонализированные консультации по уходу, питанию и здоровью ежей на основе данных вашего питомца.

## 🌟 Возможности

### 🦔 Персонализированные консультации
- **Учет индивидуальных параметров**: порода, возраст, вес вашего ежа
- **Экспертные рекомендации**: ответы на вопросы о содержании, питании, гигиене
- **Анализ веса**: проверка соответствия породным нормам

### 📋 Управление анкетами
- Создание и редактирование анкет для нескольких ежей
- Хранение истории данных ваших питомцев
- Быстрый доступ к информации о каждом еже

### ⚠️ Безопасность прежде всего
- **Автоматическое определение критических ситуаций** (кровь, судороги, травмы)
- **Экстренные предупреждения** с рекомендацией немедленно обратиться к ветеринару
- **Медицинские дисклеймеры** для вопросов о здоровье

### ❓ Универсальные консультации
- Ответы на общие вопросы о ежах без необходимости создания анкеты
- База знаний по содержанию и уходу

## 🚀 Как начать

1. **Найдите бота в Telegram**: [@HedgeAiCare_bot](https://t.me/HedgeAiCare_bot)
2. **Запустите командой**: `/start`
3. **Создайте анкету ежа** в разделе "➕ Добавить ежика"
4. **Задавайте вопросы** через "🦔 Задать вопрос про моего ежика"

## 📊 Основные функции

| Функция | Описание |
|---------|----------|
| **🦔 Задать вопрос про моего ежика** | Персонализированные ответы с учетом данных анкеты |
| **📋 Анкеты моих ежиков** | Просмотр и управление профилями питомцев |
| **❓ Задать вопрос без анкеты** | Общие консультации о содержании ежей |
| **➕ Добавить ежика** | Создание новой анкеты |
| **🌿 Сверить с породной нормой** | Анализ веса и соответствия стандартам породы |

## 🏥 Важная информация

> ⚠️ **Внимание**: Бот не заменяет консультацию ветеринара-ратолога! 
> 
> - При критических симптомах немедленно обращайтесь к специалисту
> - Полученные рекомендации носят справочный характер
> - Ответственность за здоровье питомца лежит на владельце

## 🔧 Технологии

- **AI**: GigaChat API для генерации ответов
- **База данных**: PostgreSQL для хранения анкет
- **Фреймворк**: python-telegram-bot
- **Хостинг**: Render (24/7 доступность)
