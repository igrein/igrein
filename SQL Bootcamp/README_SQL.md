# SQL Bootcamp - 12 Days of Practice

Эта диреткория содержит мои решения 12-дневного интенсивного курса по SQL, охватывающего ключевые аспекты работы с базами данных.

## 📚 Содержание

- **Основы SQL** - SELECT, фильтрация, сортировка, агрегация
- **Продвинутые запросы** - JOIN, подзапросы, оконные функции  
- **Транзакции и изоляция** - ACID, аномалии параллельного доступа
- **Оптимизация** - индексы, представления, производительность
- **Администрирование** - пользователи, права доступа, бэкапы
- **Data Warehousing** - ETL, хранилища данных, аналитические запросы

## 🛠 Технологии

- PostgreSQL
- Advanced SQL features
- Query optimization
- Database design patterns

## 📁 Структура

Каждый соответствует одному дню обучения с практическими заданиями и решениями.
На картинках изоображены структуры баз данных, с которыми проводилась работа. 
Также в отдельной папке лежат скриншоты выполнения запросов на аномалии 10 дня

## 🎯 Цель

Освоить продвинутые техники SQL для решения реальных бизнес-задач и построения эффективных запросов к базам данных.
