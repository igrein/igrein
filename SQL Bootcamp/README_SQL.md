# SQL Bootcamp - 12 Days of Practice

Эта директория содержит мои решения 12-дневного интенсивного курса по SQL, охватывающего ключевые аспекты работы с базами данных.

## 📚 Содержание

- **Основы SQL** - SELECT, фильтрация, сортировка, агрегация
- **Продвинутые запросы** - JOIN, подзапросы, оконные функции  
- **Транзакции и изоляция** - ACID, аномалии параллельного доступа
- **Оптимизация** - индексы, представления, производительность
- **Администрирование** - пользователи, права доступа, бэкапы
- **Data Warehousing** - ETL, хранилища данных, аналитические запросы

## 🛠 Технологии

- PostgreSQL
- Advanced SQL features
- Query optimization
- Database design patterns

## 📁 Структура

В директории "Решения" каждый файл соответствует одному дню обучения с практическими заданиями и решениями.
В директории "БД" содержится информация  о структурах баз данных, с которыми проводилась работа. 
В директории "Скриншоты ДЕНЬ 10" лежат скриншоты выполнения запросов на аномалии 10 дня

## 🎯 Цель

Освоить техники SQL для решения реальных бизнес-задач и построения эффективных запросов к базам данных.
